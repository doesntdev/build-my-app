## Summary
User-visible change and non-goals. Link the canonical issue.

## Coordination
Claim, intended base, scope, dependencies and current overlap recheck.

## Evidence
Actual local commands/results, current commit, CI and user-flow verification.

## Security and data
Auth/tenant/API/MCP/events/migration effects, compatibility, new secret names only.

## Release and operations
Deploy order, provider/config/email/DNS changes, observation and failure thresholds,
rollback/forward-fix, cost impact. Record staging and production separately.

## Follow-ups and limits
Known risks, linked follow-up issues, untested behavior. Use a closing issue link
only if merge genuinely completes the issue, not before required deployment proof.
